# Security

Security fixes go into the latest release only.

To report a vulnerability, use [Report a vulnerability](https://github.com/GooZhenJie/skywrite/security/advisories/new) on the Security tab instead of opening a public issue. Include the steps to reproduce it and your Skywrite and macOS versions.

Examples of what to report:

- Skywrite installing an update that isn't signed with its update key
- Another app or website reading or changing notes through Skywrite
- Network requests other than the update check

The first-launch warning described in the [README](README.md#first-launch) is expected and isn't a vulnerability.
